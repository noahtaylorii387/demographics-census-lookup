## Overview

Census Demographics Lookup offers a lightweight way to examine census tract demographic data from an HTML interface. Its design keeps the lookup process direct and accessible without requiring a large or complicated application environment.

The project is intended for users who work with census reference information and prefer a straightforward browser-based tool. As an HTML application, it can be opened with minimal preparation and can also fit naturally into a static web hosting workflow.
